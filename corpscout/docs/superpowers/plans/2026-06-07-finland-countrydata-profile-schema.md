# Finland Countrydata Profile Schema Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement `countrydata_finland` country-level profile storage for Finland PRH YTJ v3 data, projected from the existing source-level raw schema.

**Architecture:** Keep `countrydata_finland_prh_ytj` as raw/audit/source storage and add `countrydata_finland` as the queryable country profile schema. The scheduler DB store will upsert PRH raw records, then project changed records into concrete country profile tables in the same transaction. sqlc owns all database write/read shapes; Go code creates sqlc params directly from PRH records without generic facades.

**Tech Stack:** PostgreSQL migrations, sqlc, Go 1.26.1, pgx v5, `github.com/cockroachdb/errors`, `log/slog` only at process boundaries.
