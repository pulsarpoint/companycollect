# Company data sources for Jordan

## Status

- Official bulk data: **partial** (open data has individual-institution and sector/list datasets)
- Official API: **found** (CKAN API on `opendata.gov.jo`)
- Open data portal: **found**
- License: **Open Jordanian License**
- Recommended ingestion path: **manual review / partial ingestion**, not a full company-register source yet

## Best source

The best company-adjacent source found is **Table of individual institutions 2**
from the Ministry of Industry, Trade & Supply. It is a public CSV of individual
institutions with registration number, governorate, registration date, capital,
status, national number, institution name, trade name, area/city/street.

This is not a complete company registry. It is useful for sole-proprietor /
individual-institution coverage and for understanding whether Jordan should get
a source package later.
