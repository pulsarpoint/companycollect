# Jordan schema notes

## Individual institutions fields observed

- `الرقم_المتسلسل` - serial id.
- `رقم_المؤسسات_الفردية` - individual institution number.
- `المحافظة` - governorate.
- `تاريخ_التسجيل` - registration timestamp.
- `رأس_المال_المسجل` - registered capital.
- `جنسية_صاحب_المؤسسة_الفردية` - proprietor nationality.
- `حالة_المؤسسة_الفردية` - status.
- `الرقم_الوطني` - national number / identifier.
- `اسم_المؤسسة_الفردية`, `الاسم_التجاري` - institution/trade name.
- `المنطقة`, `المدينة`, `الشارع` - address fields.

## Mapping

- `registration_number`: individual institution number
- `legal_name`: institution/proprietor name; personal-data review required
- `trade_name`: trade name
- `lifecycle_status`: institution status
- `registered_address`: area/city/street
