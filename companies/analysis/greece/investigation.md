# Greece — Company Open Data Investigation

## Conclusion

Greece is a **partial-open** country. The authoritative register, **GEMI** (Γενικό Εμπορικό Μητρώο / General
Commercial Registry, Law 4919/2022), offers **free manual company search** but **no open bulk export**, and its
underlying API is **undocumented, rate-limited and reCAPTCHA-protected** — so lawful automated/bulk ingestion is
**blocked**. Financial statements are public but **document-based (PDF)**. Everything joins on the **GEMI number**
and the **ΑΦΜ** (AFM, 9-digit tax/VAT id).

## What was verified (live)

- **GEMI publicity portal** `publicity.businessportal.gr` and EN `businessportal.gr/en/home-en/` → HTTP 200.
  Free manual search by company name / GEMI number / ΑΦΜ.
- **GEMI `/api`** probing:
  - `/api/opendata`, `/api/opendata/companies`, `/api/companies/search` → HTTP 404.
  - `/api/search` → HTTP 500/`{"message":"Error"}` (live but wrong params).
  - Repeated calls → **HTTP 429 Too Many Requests** (aggressive rate limiting).
  - Portal HTML contains **`recaptcha/api.js?render=6Ldo…`** → the API is **reCAPTCHA-protected**. Automated
    access requires a reCAPTCHA token generated by the SPA. **Not bypassed** (would violate access controls).
- **AADE RgWsPublic** SOAP `https://www1.aade.gr/webtax2/wsgsis/RgWsPublic/RgWsPublicPort` → HTTP 200 (reachable),
  but the service **requires registered TaxisNet web-service credentials**; returns company basic data by ΑΦΜ.
- **VIES** `checkVatService` → HTTP 405 (needs SOAP POST) — validates EL VAT.
- **data.gov.gr** → HTTP 200 root; it is a **curated statistical** open-data API (token-gated), **not** the
  company register; no GEMI/company bulk.
- **OpenSanctions** `gr_gemi` / `gr_companies` datasets → HTTP 404 (no FollowTheMoney GEMI mirror to lean on).

## Identifiers

- **Αριθμός ΓΕΜΗ (GEMI number)** — the commercial-registry id (the join key on the register side).
- **ΑΦΜ (AFM)** — 9-digit tax id, issued by AADE; the universal cross-source join key. **VAT** = `EL` + ΑΦΜ
  (for VIES).
- **ΚΑΔ** — Κωδικός Αριθμός Δραστηριότητας, the Greek activity classification (NACE-aligned).

## Financial data

- Companies must publish annual **financial statements** (οικονομικές καταστάσεις, under **ΕΛΠ** Greek GAAP or
  **IFRS**) and **balance sheets** (ισολογισμοί) to GEMI. They appear on the company's GEMI page as **PDF
  documents** (announcements/filings) — **not structured open data** (no XBRL/CSV of figures). Currency **EUR**.
- Structured financials at scale therefore require OCR/parsing of the PDFs or a **commercial provider**
  (ICAP/CRIF, Kyckr), which resell parsed financials + credit data.

## Recommended ingestion

No lawful open bulk/automation path. Options: (a) **manual** per-company lookups via the free portal; (b)
**AADE RgWsPublic** with registered credentials for tax-side basic data by ΑΦΜ; (c) a **commercial provider**
for structured financials at scale. Use **Diavgeia** and **procurement (ΚΗΜΔΗΣ)** open data as ΑΦΜ↔name
cross-references.

## Risks / open questions

- **Access controls**: GEMI API is reCAPTCHA-protected + rate-limited — must not be bypassed; treat as
  blocked for automation.
- **License**: GEMI reuse/redistribution terms are not clearly stated — confirm before any redistribution.
- **Financials**: PDF documents only (no structured open figures).
- **Credentials**: AADE RgWsPublic needs registered TaxisNet web-service access.
- **No open mirror**: no OpenSanctions/OpenCorporates bulk to substitute.
