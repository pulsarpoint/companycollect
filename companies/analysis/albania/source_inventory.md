# Albania — Source Inventory

| Source | Org | Type | Access | Formats | License | Status |
|---|---|---|---|---|---|---|
| Open Corporates Albania | Open Data Albania / AIS | official registry (open mirror) | public | HTML | open data | **recommended** |
| QKB register | QKB | official registry | free per-company extract | HTML, PDF | official register | **recommended** |
| opendata.gov.al | AKSHI | open data portal | public | CSV, HTML | open | useful_secondary_source |

## Roles

- **open_data_albania_qkb** — the QKB register as open data: company lists +
  per-company pages keyed on NIPT (name, administrator, owners, capital, activity,
  status, former names). Verified (4,459 NIPTs).
- **qkb_registry** — the official register: authoritative per-company extract +
  financial statements (bilanci).
- **opendata_gov_al** — national open-data portal.

## Join key

**NIPT/NUIS** (letter+8digits+letter) — the company id, tax id, and VAT id. Owners/
administrators are personal data.
